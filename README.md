# Carrito-frontend

Carrito de compras para una tienda de libros, construido con **HTML, CSS y JavaScript vanilla**.

## Funcionalidades

- Agregar y eliminar productos del carrito
- Control de cantidad por producto
- Vaciar carrito completo
- Persistencia con `localStorage`
- Modal nativo con `<dialog>`

## Uso

No requiere instalación, Abre `index.html` directamente en el navegador o con Live Server.
