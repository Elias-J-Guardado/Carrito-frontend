# Carrito-frontend

Shopping cart for a bookstore, built with **HTML, CSS and JavaScript vanilla**.

## Features

- Add and remove products from the cart.
- Quantity control per product.
- Clear full cart.
- `localStorage` persistance.
- Native modal with `<dialog>`.

## Usage

No installation required. Open `index.html` directly in your browser or with Live Server.
